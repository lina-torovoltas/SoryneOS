# SoryneOS
This repository serves as a testing playground for bare-metal development.</br>
The entire project is structured as a collection of FASM macros designed to build and run code directly on 16-bit hardware.</br>
If these macros expand further, they will be migrated to the main [FasmMacroLib](https://github.com/lina-torovoltas/FasmMacroLib) repository,</br>
leaving this sandbox as a dedicated environment for creating and developing my own OS.
